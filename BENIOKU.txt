GITHUB'A YUKLEME LISTESI
========================

KARAR: Sistem yapay zeka ile calismaya hazir, ama API anahtari olmadigi icin
kural bazli metinle calisiyor. Dashboard bunu rozetle belirtiyor:
"Rule-based fallback - model layer ready, awaiting API key"


1) Bu klasordeki 5 dosyayi repo koklerine yukleyin
   Code -> Add file -> Upload files -> hepsini surukleyin -> Commit changes

   analyze_data.py    guncellendi: GenAI katmani + opportunity cost
   signals.json       guncellendi: opportunity cost verileri
   index.html         guncellendi: opportunity cost karti + argument bloku
   prompts.md         YENI - prompt protokolu (odev istiyor)
   architecture.md    YENI - AWS yerine GitHub gerekcesi (odev istiyor)


2) Workflow dosyasini elle duzeltin
   Code -> .github -> workflows -> procurement_bot.yml -> kalem ikonu

   "Generate signals" adimini asagidaki gibi yapin. env blogu yeni;
   anahtar eklenmese bile bu satirlarin durmasinda sakinca yok.

      - name: Generate signals
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
        run: python analyze_data.py

   Commit changes.


3) Actions -> Procurement signals -> Run workflow
   Yesil tik beklenir. Log'da su satirlari gorursunuz:
     PP: no API key configured, using rule-based text
     ...
   Bu bir hata degil, planlanan davranis.


ILERIDE ANAHTAR ALIRSANIZ
   Settings -> Secrets and variables -> Actions -> New repository secret
   Name: ANTHROPIC_API_KEY
   Sonra Run workflow. Rozet model adini gostermeye baslar.
   Baska bir degisiklik gerekmez.
